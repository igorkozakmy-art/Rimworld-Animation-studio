## Features

- Actors: people, animals, items, buildings, plants and supported vehicles.
- Keyframes, actor groups, scale, layers, markers and looping subprojects.
- Camera animation, map switching, scene lighting and weather.
- Staged combat, abilities, Ideology and Anomaly rituals.
- Image/video clips, audio waveforms, titles and subtitles.
- Scene saving, MP4 export with audio, sound and texture export.

Available content depends on the installed game expansions and optional mods. Framework support does not guarantee every add-on works; check the in-game catalog for the current status.

## Installation and dependencies

Subscribe to Animation Studio and Harmony through their official Workshop pages. Enable Harmony before Studio and restart the game.

The built-in dependency manager groups optional integrations by feature and resolves their dependencies. Steam subscriptions and installation start only after a user action. Replacing the active mod list is explained in the manager; its previous contents are backed up.

When Workshop is unavailable, the first-run window and compatibility catalog show names, Package IDs and Workshop IDs with manual installation guidance. Obtain each optional mod from its author's official source, check its game-version support, place its folder under `RimWorld/Mods` and activate its dependencies first. No collection of third-party mod files is distributed here.

## Privacy and reports

There is no background telemetry or automatic delivery of error reports. Technical logs are written locally. A report is sent to the author only when you explicitly press **Send** in the report window. Opening the window does not send it, and reports queued by older builds are not retried automatically.

On an error, green Send and red Ignore buttons unlock after five seconds. Both choices require confirmation. Only a confirmed server receipt opens an optional suggestion form with a close button. Repeated errors are grouped.

Inspect the local file before sending: it can contain errors, the mod list, scene information, local paths and your Steam ID when available. Local logs are retained after delivery. Written feedback also requires the Send button. Using Steam integration involves requests to Steam while working with dependencies.
